# MODA URBANA
## Proyecto de Integración Continua

### Descripción
Sistema de gestión de inventario y productos
para la empresa MODA URBANA.

### Objetivo
Desarrollar una aplicación de software utilizando
herramientas de integración continua y Docker.

### Tecnologías
- Java JDK 21
- Eclipse IDE
- Docker Desktop
- Docker Compose
- GitHub

### Entrega 1 - Semana 3
Construcción de dos contenedores Docker
y configuración de su comunicación.

### Estado del proyecto
En desarrollo.
